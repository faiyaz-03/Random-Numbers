🎲 Random Numbers Game

A simple Random Numbers Game built with Java. The project generates random numbers and provides a basic game experience through the console.

This project was created as a beginner Java project to practice fundamental programming concepts such as variables, user input, conditional statements, loops, and random number generation.

📌 Project Overview

The Random Numbers Game is a console-based Java application where the program generates random numbers and interacts with the user through the terminal.

The main purpose of this project is to strengthen the fundamentals of Java programming through a small and practical project.

▶️ How to Run
1. Clone the repository
git clone https://github.com/faiyaz-03/Random-Numbers.git
2. Open the project
cd Random-Numbers
3. Compile the Java program
javac Games.java
4. Run the program
java Games
